# Methodology, data and publication boundaries

[简体中文](methodology.md) · [Project home](../README.en.md)

## Three distinct layers

1. **Full catalog:** each bilingual leaderboard and master table contains 676 unique arXiv IDs. Every paper has one primary topic and multiple possible tags. Dates retain the first-submission dates in the master tables, not latest-revision dates.
2. **Automated evidence scores:** existing scores and reasons are retained. This update checks sums, thresholds, ordering and bilingual consistency without rerunning the original scorer. The original scoring program, collection logs and full search queries are not published here; end-to-end scoring reproduction from original papers is not established.
3. **Selected detailed reviews:** the original ranking covers 328 in-window papers plus 1 historical reference, with conclusions dated 2026-08-20 and highlights through 2026-10-28. The current file includes the first 6 detailed reviews. The 50 referenced attachments for batches 2–52 are absent from the public repository. Their references are explicitly marked unpublished and preserved in a [reference manifest](unpublished-references.json). Missing reviews have not been reconstructed or invented. Catalog coverage is not full-review availability.

The corpus cutoff is **2026-11-09**. Documentation maintenance on **2026-11-14** does not imply a search of the intervening five days or exhaustive field coverage.

## Score interpretation

| Automated dimension | Maximum |
|---|---:|
| Innovation | 20 |
| Rigor | 30 |
| Grounding | 20 |
| Reproducibility | 15 |
| Engineering | 15 |

A ≥ 75, B 60–74, C 45–59, D < 45. The inherited `core` / `adjacent` labels describe collection scope; confidence labels describe the existing assessment. Neither is another rank. The separate 10-point scale in detailed reviews cannot be converted linearly to this 100-point automated scale.

Extraction can miss sections, tables or release statements. “Not identified” does not establish absence: the [OpenAnt source page](https://arxiv.org/abs/2606.19149) includes an open-source link, and [VCAO](https://arxiv.org/abs/2604.08291) states that artifacts are released. Extraction-failure wording in existing judgments should therefore prompt manual checking. Performance, CVE counts and repair rates are claims by authors or inherited reviews; this repository has not independently rerun all experiments.

## Checks performed on 2026-11-14

- Corpus-wide bilingual ID, title, first date, rank, score and dimension-score consistency: 676 unique IDs, nine topics totaling 676, grades A 7 / B 226 / C 352 / D 91.
- Source-page title/date spot checks for nine papers: [project-scale detection](https://arxiv.org/abs/2601.19239), [CVE-Factory](https://arxiv.org/abs/2602.03012), [Antaeus](https://arxiv.org/abs/2607.01138), [OpenAnt](https://arxiv.org/abs/2606.19149), [ABSENTIA](https://arxiv.org/abs/2610.00977), [VCAO](https://arxiv.org/abs/2604.08291), [Vulnerability Localization Benchmark](https://arxiv.org/abs/2609.15939) and [Sifting the Noise](https://arxiv.org/abs/2601.22952). The [Agent Audit title](https://arxiv.org/abs/2603.22853) was also checked to correct an old spelling error. This is metadata sampling, not corpus-wide external link checking or experimental validation.
- No bulk changes to existing scores, tags or judgments; no paper additions. Sources may have newer versions and should be checked again before adoption.

## Machine-readable catalog

[papers.json](../data/papers.json) and [papers.csv](../data/papers.csv) are deterministically generated by `scripts/build_catalog.py`. The bilingual leaderboards/master tables remain the sources. JSON includes `schema_version`, `corpus_cutoff`, `documentation_updated`, `source_files`, `score_origin`, `statistics` and `papers`.

Each record includes `id/title/url/rank/date/tier/score/dimensions/scope`. The `topic/tags/confidence/judgment` fields contain `zh/en` text. CSV flattens bilingual fields and separates tags with ` · `. Import the UTF-8 CSV through Excel's “From Text/CSV” command when necessary.

Checks establish internal data consistency and valid local links. They do not establish correct research conclusions, equivalent translations, runnable artifacts or permanently reachable external sites. Existing tag indexes require separate editorial review.
